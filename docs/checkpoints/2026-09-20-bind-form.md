## Construction

New `refitSkinBind()` applies one smooth model-space field to owned rest vertices
AND rest joint positions. Retains topology, UVs and weights; transports authored
normals by inverse-transpose finite-difference Jacobians; invalidates tangents and
high/low correspondence. New inverse binds follow the new rest positions. Existing
clips, morphs, nonidentity skin binds, attached static meshes, and dependent baked
normal/bump/displacement/AO/light maps are rejected, not silently reused. Inputs
must be an owned unplaced model in its captured bind pose. Sampled positive
Jacobians are not global collision/injectivity or anatomical guarantees.

This extends the existing point-field vocabulary rather than a second human
builder. [API](../refit-skin-bind.md) and
[written source notes](../research/rest-shape-and-skin-bind.md).

Optional `form: tailored` on the actual Xbot uses that operation before authoring
clips. The leg chain grows **0.888992 -> 0.958908 m** while rest height stays
unchanged; hip-root height **1.039915 -> 1.101628 m**, knee height **.528693 ->
.563590 m**, shoulder height **1.437780 -> 1.440642 m**. The torso's width/depth
are reduced. Upper arm changes **.278415 -> .274056 m**, forearm **.283288 ->
.282853 m**: lengths ARE deliberately refitted, then preserved by pose solving.
These are design choices, not anatomy extracted from the reference.

New `silhouette` is a separate far-arm pose edit after `poised`: the Right wrist
moves from [-.16,.92,-.04] to [-.21,.90,-.005] meters, with a small clavicle roll.
The same scene camera/lights, near-hand target and ankle targets remain. It avoids
leaving the stock wrist target inside the raised thigh. `stock` and all earlier
pose definitions stay available. Original source animations are not represented
as retargeted to the new bind. The detailed android remains untouched.

An independent flexible-tail fixture uses the same refit to lengthen, sweep and
taper a four-bone skin, then authors a bend on the new bind. No extra geometry,
shader, texture, normal bake or imported tutorial mesh was added. The Xbot input
and all derived geometry retain Adobe/Mixamo provenance.

## Visual judgments and rejected trials

The retained design has more leg length relative to its torso, a less bulky chest,
and a visible far-hand contour rather than fingers emerging through the thigh.
The difference is clearer in T-bind and clay comparisons. It is NOT an accepted
confident likeness: the stock faceless head, segmented shoulder/waist gaps, rib
cover outline, foot shapes and remaining arm/body overlaps still differ. No
physical balance, collision-free skin or anatomical reconstruction is claimed.

A wider/higher far-hand target made the arm too bent and raised the hand relative
to the intended hang. The lower/narrower target was retained after side views.
More ambitious lower/forward targets correctly failed the fixed-length solve;
no bone stretching or target clamping was added to rescue them.

One initial field-agreement check incorrectly compared to the source's evaluated
rest skin, whose authored inverse binds already differ from raw rest vertices
by 1.36e-6 m. The operation acts on RAW bind geometry; corrected that comparison
and separately recorded the source's approximation, retaining the original
5e-7 criterion. The actual refitted field agrees within 1.12e-7 m. No validation
threshold was loosened. A second review detected changed source fingerprints
while implementation was still underway; it remains failed. The first tail
comparison was also cropped because the old frame had insufficient margin for
the longer bind. The final review uses one larger FIXED fixture frame for both
versions and asserts all frames are unclipped. The character camera is unchanged.
